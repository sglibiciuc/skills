# sglibiciuc/skills

Открытые плагины и навыки Саши Глибичука для ИИ-ассистентов. Репозиторий заодно служит каталогом плагинов (marketplace) с именем `sglibiciuc`.

## Координатор

![Координатор: от идеи до работающего продукта](assets/coordinator-cover.png)

Координатор 1.0.0 работает как плагин для Claude Code и Codex. Вы говорите с одним агентом, Координатором. Он расспрашивает, что вам нужно, и договаривается с вами, как это будет работать. Потом команда агентов с разными ролями собирает результат и проверяет его. На выходе готовая вещь, которой можно пользоваться: автоматизация, навык, плагин, сайт или приложение.

Плагин нужен тем, кто работает в Claude Code или Codex и хочет получить работающую вещь, а не ответ в чате. Можно прийти с готовым описанием или ТЗ, а можно попросить проверить или доработать то, что у вас уже есть.

Как идёт работа:

1. Координатор задаёт вопросы по одному и к каждому предлагает ответ. Можно ответить «решай сам».
2. Показывает два коротких документа: «чего вы хотите» и «как это будет работать». Вы согласуете каждый.
3. Показывает план и спрашивает, начинать ли.
4. Собирает и проверяет результат. После каждого готового куска пишет одну строку о ходе работы.
5. Отдаёт готовую вещь и инструкцию, как ей пользоваться.

Ваши файлы Координатор не правит. Работа идёт в копиях, и копия становится рабочей только после вашего «да».

Что нужно: Claude Code или Codex и Python 3. Проверить Python можно командой `python3 --version`.

### Установка в Claude Code

1. В сеансе Claude Code подключите каталог:

   ```
   /plugin marketplace add sglibiciuc/skills
   ```

2. Установите плагин:

   ```
   /plugin install coordinator@sglibiciuc
   ```

   То же самое из терминала, без запуска сеанса:

   ```bash
   claude plugin marketplace add sglibiciuc/skills
   claude plugin install coordinator@sglibiciuc
   ```

3. Проверьте: команда `claude plugin list` показывает `coordinator@sglibiciuc` со статусом `enabled`.

### Установка в Codex

1. Подключите каталог в терминале:

   ```bash
   codex plugin marketplace add sglibiciuc/skills
   ```

2. Установите плагин:

   ```bash
   codex plugin add coordinator@sglibiciuc
   ```

3. Проверьте: команда `codex plugin list --marketplace sglibiciuc` показывает `coordinator@sglibiciuc` со статусом `installed, enabled`.

4. Откройте терминал в папке, где хотите работать над задачей, и запустите новый сеанс `codex`: плагин подхватывается только в новом сеансе. При первом запуске Codex покажет окно `Hooks need review`. Нажмите один раз стрелку вниз, чтобы выделился пункт `2. Trust all and continue`, и нажмите Enter. Хуки не дают Координатору бросить работу на полпути и возвращают его к задаче после перерыва.

### Как начать

1. Откройте терминал в папке, где хотите работать над задачей, и запустите `claude` или `codex`.
2. Вызовите Координатора и напишите, что хотите получить:
   - Claude Code: наберите `/coordinator:coordinator` и через пробел запрос, например `/coordinator:coordinator хочу каждое утро получать сводку новых писем от клиентов`.
   - Codex: наберите `@`, выберите в списке `coordinator (coordinator)` и нажмите Enter. В поле ввода появится `$coordinator:coordinator`. Через пробел напишите запрос.
3. Чтобы вернуться к задаче в другой раз, запустите Claude Code или Codex в той же папке и напишите «продолжай».

Для каждой задачи Координатор заводит отдельную папку: ваши ответы, согласованные документы, план, отчёты и бэклог. Подробное описание плагина на русском и английском: [plugins/coordinator/README.md](plugins/coordinator/README.md).

## Навыки

Отдельные навыки лежат в `skills/`. Подробности в `SKILL.md` или `README.md` внутри каждой папки.

| Навык | Язык | Что делает |
|-------|------|------------|
| [autonomous-loop-onboarding](skills/autonomous-loop-onboarding/) | EN | Расспрашивает, какими инструментами вы пользуетесь, и настраивает автономный цикл задач. Вы ставите задачу в своём менеджере задач, ИИ-агент её выполняет, сам проверяет и возвращает вам на одобрение. |
| [clear-writing](skills/clear-writing/) | RU | Пишет, правит и проверяет деловые письма и сообщения по методу Максима Ильяхова и Людмилы Сарычевой. |
| [mnemaos](skills/mnemaos/) | EN | Расспрашивает вас и собирает личную память для ИИ: папку с Markdown-файлами на вашем компьютере. ИИ читает её в начале сеанса и дополняет в конце. Можно начать с нуля или взять за основу папку, которая у вас уже есть. Описание: [docs/mnemaos/](docs/mnemaos/). |
| [mnemaos-mcp](skills/mnemaos-mcp/README.md) | EN | Дополнительный сервер памяти для mnemaos. Отдаёт ту же папку памяти любому MCP-клиенту, на вашем компьютере или с вашего сервера. Нужен Python 3.9 или новее, сторонних библиотек нет. Это сервер, а не навык: настройка по его [README](skills/mnemaos-mcp/README.md). |
| [thoughts-to-doc](skills/thoughts-to-doc/) | EN, говорит на любом языке | Задаёт вопросы по одному, пока ваша мысль не сложится в один простой документ, по которому человек или ИИ-агент сможет действовать. |

### Как установить отдельный навык

1. Один раз скачайте репозиторий:

   ```bash
   git clone https://github.com/sglibiciuc/skills.git
   ```

2. Из той же папки скопируйте папку навыка туда, где ваш ассистент ищет навыки. Вместо `clear-writing` подставьте нужный навык.

Claude Code:

```bash
mkdir -p ~/.claude/skills
cp -r skills/skills/clear-writing ~/.claude/skills/clear-writing
```

Codex:

```bash
mkdir -p ~/.agents/skills
cp -r skills/skills/clear-writing ~/.agents/skills/clear-writing
```

После копирования начните новый сеанс. Подробнее про Codex: [docs/README.codex.md](docs/README.codex.md). Gemini CLI и чаты без поддержки навыков описаны только там, где об этом говорит README самого навыка, например [skills/thoughts-to-doc/README.ru.md](skills/thoughts-to-doc/README.ru.md). Отдельные навыки в Gemini CLI: [docs/README.gemini.md](docs/README.gemini.md).
