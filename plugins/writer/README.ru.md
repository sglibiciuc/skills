# Writer

![Writer](assets/cover.png)

[English](README.md)

Writer помогает сформулировать то, что вы хотите сказать, и подготовить текст для его читателя: письмо клиенту, пост, задача подрядчику или текст выступления. Можно принести заметки, готовый черновик, входящее письмо или просто описать задачу.

Перед новым текстом Writer сверяет с вами смысл: кому пишем, что человек должен понять или сделать и какие обещания вы готовы дать. А согласованный профиль помогает учитывать ваш голос и привычки в следующих текстах. Например, начинать письмо сразу с просьбы, обращаться к клиенту по имени или обходиться без рекламных эпитетов.

Работает в Claude Code, Codex, claude.ai и Cowork.

## Установка

В Claude Code и Codex нужны поддержка плагинов и Python 3 для встроенных проверок. Дополнительные библиотеки Python не требуются.

В Claude Code выполните:

```text
/plugin marketplace add sglibiciuc/skills
/plugin install writer@sglibiciuc
```

Для Codex выполните в терминале:

```sh
codex plugin marketplace add sglibiciuc/skills
codex plugin add writer@sglibiciuc
```

В claude.ai и Cowork можно установить Writer как навык. Скачайте [репозиторий](https://github.com/sglibiciuc/skills) и упакуйте папку `plugins/writer/skills/writer` целиком в ZIP. Откройте Customize, выберите Skills, нажмите «+», затем Create skill и Upload a skill. Загрузите архив и включите навык. Для claude.ai также должно быть включено выполнение кода: Code execution and file creation.

Начните новый чат после установки. Вызовите `/writer:writer` в Claude Code, укажите `$writer` в запросе к Codex или напишите «Используй Writer» в Claude. Дальше пишите обычными словами.

## Первый текст

Пока профиля нет, Writer в каждом новом чате один раз предложит настроить его сейчас или позже. Он добавит короткую строку к обычному ответу и продолжит вашу задачу. Если вы просто поздоровались, приглашение прозвучит при знакомстве.

Начать можно так:

> Напиши ответ поставщику. Новую цену принимаю с 1 декабря. На годовой контракт пока не соглашаюсь. Вот его письмо…

Здесь уже есть адресат, решение и граница обещаний. Writer кратко повторит задачу и сразу подготовит ответ. Если написать только «Ответь поставщику» и приложить его предложение, Writer сначала спросит, что вы хотите принять, отклонить или предложить взамен.

Для нового текста с неполным заданием он сначала предложит своё понимание задачи. Вы сможете подтвердить его или поправить. После ответа Writer продолжит работу над тем же текстом. Так можно заметить неверно понятый смысл до того, как он превратится в убедительно написанный черновик.

При редактировании назовите проблему: «сократи до 300 знаков», «слишком официально», «убери признаки нейросети». Тогда Writer сразу возьмётся за правку. На просьбу «оцени, переписывать не надо» он даст замечания и оставит текст как есть.

## Что ему поручить

| Задача | Пример запроса |
| --- | --- |
| Написать с нуля | «Составь задачу подрядчику по этим заметкам» |
| Ответить на сообщение | «Откажи в скидке, сохрани доброжелательный тон. Новых условий не предлагай» |
| Подготовить текст для другой аудитории | «Сделай из этой служебной записки пост для клиентов» |
| Сократить | «Уложи объявление в 500 знаков, сохрани даты и адрес» |
| Найти формулировку | «Предложи пять тем письма об окончании распродажи» |
| Проверить | «Покажи, где читателю непонятно, чего от него хотят» |

Writer также пишет пресс-релизы, речи, тексты слайдов, слоганы и названия. Можно заказать несколько материалов по одному поводу. Исходники прикладывайте в чате или файлом. Работа с Word, PDF и Google Docs зависит от доступных инструментов вашей среды.

## Чтобы текст был похож на ваш

Профиль нужен, когда «ясно и грамотно» ещё не означает «мне нравится». В нём можно закрепить ваш способ обращаться к людям, характерные формулировки и правила компании, чтобы не повторять их в каждом задании.

Можно принять приглашение или попросить настройку самому:

> Настрой Writer под меня. Я руковожу небольшой командой, пишу клиентам и веду профессиональный канал. Хочу сохранить свой голос.

Writer уточнит, кто вы и что пишете, попросит 3–5 ваших текстов и изучит редполитику, если она есть. Образцы нужны, чтобы описать вашу манеру письма. Редполитика задаёт требования компании: обращения, терминологию, оформление и допустимый тон. Затем Writer покажет весь проект профиля и сохранит его после вашего согласия. Уже существующий профиль дополняется с учётом новых решений.

Предпочтения можно уточнять и по ходу работы. Если вы поправили правило о себе или компании, Writer предложит его запомнить с конкретной областью действия: «В письмах клиентам обращаться по имени. Запомнить?» Деталь одного письма, например новая дата встречи, не должна становиться общим правилом. Редполитику, приложенную к задаче, Writer применит к этому тексту и предложит сохранить для следующих.

Перед новым текстом, правкой или проверкой Writer читает доступный профиль. В среде с файлами можно хранить общий профиль и отдельные правила проекта. Они лежат вне плагина и сохраняются при его обновлении. В claude.ai Writer подготовит согласованный профиль или новое правило для вставки в инструкции проекта: файлы его рабочего окружения между чатами не сохраняются.

## Что происходит перед выдачей

Writer проверяет полный черновик на шаблонные обороты, канцелярит, следы ответа чат-бота и заданный вами предел длины. Найденная фраза требует решения по смыслу: уместную цитату или нужную формулировку можно оставить. Цель проверки — помочь тексту, а не убрать из него все совпадения со списком.

Это проверка формулировок и длины. Достоверность фактов по внешним источникам она автоматически не устанавливает. Writer должен сохранять ваши факты и договорённости, а решения о новых обязательствах остаются за вами.

Результат можно получить в чате или нужном файле. При правке файла исходник сохраняется, новая редакция записывается отдельно.

Писать можно на любом языке. Отдельные наборы языковых проверок есть для русского и английского, для остальных языков используются общие проверки. Перевод, программирование, юридическая экспертиза и промпты для агентов не входят в задачи Writer.
