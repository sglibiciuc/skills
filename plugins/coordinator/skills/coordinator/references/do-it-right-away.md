# Do it right away

Rules for the path "Do it right away". The order of steps is in SKILL.md. Everything in `coordinator.md` about talking with the person still applies.

- For a one-off action or a small change to something that exists. No research, PRD, spec or plan.
- If something already exists, the researcher first reads it, retells it and makes a copy in `copies/` (job "existing thing"), before the goal check.
- Check the goal with the person in one or two sentences, and wait for the answer. If a working thing changes, one "yes" in the same check covers the work, the copy and the replacement: "I will change X, do it in a copy, check it and replace the working one, yes?". Write the request and the answer to `interview.md`.
- The executor does it with a fresh context, in the copy. The result tester compares the result with the request before it is shown. Only after its report does a second executor launch (job "replace") replace the working thing with the copy, on the "yes" already given, and remove the copy.
- Findings and ideas from the reports go to `backlog.md` next to the result, or next to the existing thing when it changed, created by the executor in this path too. No instructions file and no final message are needed: show the result in a few plain sentences.
- If it turns out harder than one request, stop: "this is more than one request, let's take the full path". Nothing done is thrown away.
