# Improve

Rules for the path "Improve". The order of steps is in SKILL.md.

- The same path in the size of the change. The researcher reads the thing and its backlog, retells it, reproduces bugs by reading only and groups them by root. The Coordinator decides what goes into the change.
- Small means "Do it right away". Otherwise a change brief, a change PRD with a section "what changes and what must not break", and a change spec, by the main path.
- Work happens in a copy. Old behaviour is checked the same way as the new. The copy becomes the working thing as the last step of the plan, on the person's "yes".
- A new plan approval in the same task folder writes a new `.coordinator/approved`, which cancels the earlier `final` record.
